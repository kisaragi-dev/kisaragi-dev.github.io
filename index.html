KISARAGI Uploader

KISARAGI Uploader は、ブログ「kisaragi」の運営者が個人で使用するデスクトップツールです。運営者自身が制作した短い動画を、TikTok の公式 API（Login Kit / Content Posting API の video.upload）を使って運営者自身の TikTok アカウントの受信箱へ下書きとしてアップロードします。

  • 自動での公開は行いません。投稿内容の確認・編集・公開は、運営者が TikTok アプリ上で手動で行います。
  • 一般の利用者向けに提供・販売するサービスではありません。
  • 保存する情報は運営者自身の TikTok 認証情報のみで、運営者の PC 内にのみ保存します。

利用規約 ／ プライバシーポリシー

English

KISARAGI Uploader is a personal desktop tool used only by the owner of the blog "kisaragi". It uploads short videos made by the owner to the owner's own TikTok inbox as drafts using TikTok's official Login Kit and Content Posting API (video.upload). Nothing is posted automatically; the owner reviews and posts manually in the TikTok app. It is not offered to the public.
